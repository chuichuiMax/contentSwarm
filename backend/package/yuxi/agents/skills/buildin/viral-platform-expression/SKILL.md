# 平台表达规范

以共享规则快照为准，替换不得改变数字和事实。

- 标题、正文、话题按 `forbidden_lexicon.alternatives` 的知识库映射选候选，不串接或自造；空候选改写。公式锁定词条原样提交，由程序统一替换。
- 禁止无据绝对化宣传：百分百、保证、绝对、零风险、最便宜。
- CTA 给具体且克制的咨询理由；禁止要求评论、私信、发送户型或项目、暗号互动及空泛强引导。
- 可收在实用判断、注意事项或服务边界，不强制行动号召。
