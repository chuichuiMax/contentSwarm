# 平台表达规范

以规则快照中的问题词映射和 CTA 限制为准。替换后仍要自然，且不得改变数字、报价或事实含义。

- 正文和标题中的“最”按当前运营口径写成“蕞”；禁止残留高风险绝对化宣传，如百分百、保证、绝对、零风险、最便宜。
- CTA 给读者一个具体但克制的咨询理由，例如“报价先把范围核对清楚”“改造前先看现场条件”。
- 禁止要求用户评论、私信、发送户型、发送项目或用暗号互动；不要写“有装修需要找我”一类空泛强引导。
- 可以收在实用判断、注意事项或服务边界上，不强制每篇都出现行动号召。
