# 报价表达

只有存在可用于正文的价格 Evidence 或锁定报价公式时才写价格。先读取规则包中的 `price_policy`，再核对每个价格的城市、项目或工种、单位、价格类型、包含范围和来源。

- 区分标准单价、业主原报价、项目预算、工长测算与实际成交价；原类型不得改名。
- 长沙拆除等城市工种单价只能使用同城市、同工种、同单位证据。找不到匹配证据就删掉该数字并说明需现场核对，禁止借用其他城市价格。
- 标准单价只能作为参考，不得乘面积后宣称本项目成交总价；项目合计必须来自同一范围的已验证明细或明确总价证据。
- 当 `explicit_total_mode=authoritative` 时保持明确总价的原始口径；当 `itemized_list_mode=may_be_partial` 时，不能核成总价的分项按未穷尽清单表达；只有 `sum_claim_mode` 允许时才能声称这些分项构成合计。
- 金额、单位、范围和项目名称逐字保持，正文引用的价格 Evidence ID 写入对应 paragraph_evidence。
