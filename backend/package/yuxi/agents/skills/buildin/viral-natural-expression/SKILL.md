# 自然口语与去机械化

让内容像一位真实工长在讲具体工地。用具体名词和动作、自然停顿及长短句变化，保留原有事实、数字、价格、结构和 Evidence。

- 删除报告腔、报幕句和写作过程说明，如“首先、其次、综上、值得注意的是、通过以上内容、先说背景、再看过程、最后看结果”。
- 避免连续段落使用相同开头、整齐到机械的句长、每段固定总结句和空泛形容词。
- 可从规则快照的 popular_expression_pool 选择 0～2 个符合场景的口语表达；不强塞热词、不连用网络词、不用热词替代专业信息。
- 语气可以有人情味和现场感，但不得制造情绪事实、业主反馈或施工结果。
- 当前锁定的 `expression_guidance` 存在时（标准流程位于 `payload.production_pack` 内），读取其中 `role=tone_reference` 的全部召回片段，抽取与本次主题匹配的语气、停顿和自然句式；不得复制片段中的人物、城市、数字、报价、经历、反馈或承诺。
- 表达参考只能改写已有 Evidence 支持的内容。参考片段与锁定爆款结构、公式、渠道或用户要求冲突时，服从锁定规则和真实 Evidence。
- 标准生产回修删除重复句或移动人设时，同步检查对应 Emoji：移到保留的身份、数据或动作句旁，不能留在失去对应语义的位置；遵守冻结 `expression_policy`，禁用时不补符号。
