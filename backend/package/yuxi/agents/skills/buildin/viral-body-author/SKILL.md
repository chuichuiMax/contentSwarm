# 爆款正文仿写

读本篇要求、业务资料与完整爆款原文。

## 只选一个组合

AI 创作前自行选定下表一种手法及固定语气；用户指定时采用指定项。按资料特点和原文叙事选型，不因缺少情节退回报价说明。先按输出契约记录选择，再写全文，不混合手法。原始 `persona.tone` 不改，成稿用选定语气。

| 手法 | 固定语气 | 全文取材与表达 |
| --- | --- | --- |
| 兴奋真香型 | 直白说真话，坦诚、接地气 | 用家常话直说真实服务值在哪、适合谁，不硬喊“真香”，不夸张、不催单。 |
| 老师傅掏心窝 | 直白说真话，坦诚 | 从干活人的观点和交流展开，报价前后都说实在话。 |
| 公司故事型 | 自信克制，稳重踏实 | 用团队经历与做事方式串起项目和报价，不写企业宣传。 |
| 设计品味型 | 严谨专业 | 围绕居住需求、设计选择与空间感受讲取舍，专业但听得懂。 |
| 案例证明型 | 经验老道笃定，自信但不浮夸 | 串起项目需求、沟通、施工与反馈，让故事推进，不只介绍报价。 |
| 痛点共鸣型 | 共情型 | 接住一个核心顾虑，以情境和回应逐步化解，结尾呼应。 |
| 反差价值型 | 有耐心 | 围绕同口径对比解释价值与取舍，耐心讲明差异。 |
| 本地信任型 | 朴实接地气 | 围绕在本地干活、和业主交流的日常，建立亲近感。 |

## 贯穿全文

先盘点资料：年龄、年限、城市、简介、技能、推荐数、服务工地数、优势、项目地址、面积、户型、报价与标签含义全部自然融入正文，可合并重复含义，不能漏独立信息。不用“标签是、展示价”等字段话术。编号、图片 URL／对象键、模板 ID 不进正文；语气用于表达。

沿原文推进与衔接仿写，开头到结尾服务选定主线，报价后继续讲事情，不套“解释报价—优势—总结”。资料缺少的客户经历、沟通、施工情节和反馈允许合理补写，保留原文段落的叙事作用；不因没有记录就删掉故事。不机械搬用他人身份地点，不与已知项目阶段冲突。

已有数字、参数和报价逐字保留，不换算、凑整或重算。允许补写同口径对比价格、预算及节省金额，差额须算对；它们与新增情节记为创作补充，不当作输入事实。不得改写原报价或扩大范围，不把施工队写成有资质的公司，不新增保证承诺。

选型与创作补充记录放在内部元数据，不混入发布正文。交稿前核对资料覆盖、报价与单一口吻，亲切真诚、不堆营销话术，表情自然。遵守输入输出契约及标签要求；结构化流程沿用锁定报价占位和输入证据 ID，公式不强制段序。
