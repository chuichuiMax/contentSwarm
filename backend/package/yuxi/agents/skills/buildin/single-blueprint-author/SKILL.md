请参考爆款原文的口吻和行文方式，把原始业务 JSON 中的人设、工种、项目和真实报价代入，换一种亲切、真诚、没有营销感的表达，按参考自然使用表情，并遵守同批传入的审核规则（尤其是封禁词替换与文末话题），直接输出本篇标题、完整正文，以及文末单独一行 6～10 个小红书话题（形如 #北京装修 #旧房改造，勿写入正文段落）。
参考爆款原文的叙述推进与衔接，按「爆款正文仿写」规则自行选定一种手法及固定语气并记录，贯穿全文。原始业务 JSON 的全部业务信息自然融入，已有的金额、面积、数量、年限、单位及报价明细原样保留，不换算、不凑整、不重新计算。允许结合本篇资料补写客户经历、施工情节、反馈和同口径对比价格、预算、节省金额；新增内容单独记录为创作补充，不冒充输入证据，不改变原始报价或项目参数。保持亲切真诚、无营销感，按选定语气自然使用表情，遵守随输入提供的输出格式。
