# 已准备参考选择

## 创作类型与组合约束

前端选定的创作类型是硬约束。策略候选中的 direction_code 非空时，只能使用该类型及其公式候选、direction_blueprint 层级和词组组合，不得因为原文更像其他类型而改方向。装修参考卡的 content_type_code 必须与策略方向一致；同属价格营销不代表项目单价、单价+面积、工种总价、人工+辅材可以互换。

所选类型表规定的信息层顺序、组别、组数优先于爆款蓝图；参考蓝图只在本行组合允许的范围内指导钩子、段落节奏和排版。不得以“服从冻结爆款蓝图”为由省略所选类型的层级或添加禁止的层。无同类型参考时明确报缺，不降级选其他类型；业务资料缺失时指出缺失，不虚构事实凑词组数量。


只在仿写模式执行。候选仅来自本次 `reference_candidates`；不得使用知识库段落、文件名或自行搜索到的片段替代完整文章资产。

先对照当前简报与证据中的已有事实检查参考卡与 structure_preview。同一创作类型内可跨不同项目主题借鉴抽象叙述结构，但不能把报价清单改称案例过程就视为完成仿写，也不能复制原文价格、从业年限或效果。

先读取 `runtime_config_snapshot.reference_policy`。当 `required_slot_mode=mapped_facts_only` 时，每张参考卡的 `required_slots` 描述该爆款自身的信息块，不是本篇必须补齐的固定资料清单。当前投喂数据能承接核心主题和 `minimum_mapped_slots` 规定的槽位数即可选择；`slot_mapping` 只提交真实承接的槽位。其余信息块按 `unmapped_block_mode` 省略或改写为通用建议，不得新增数字、项目经历、已发生结果或服务承诺。当规则要求完整映射时，仍须覆盖该卡全部 `required=true` 槽位。

1. 检查行业、渠道、受众、场景、目标和事实槽位。依赖分项价格但只有总预算，依赖真实前后对比但只有计划，均淘汰；不能用不相干案例或原文事实填补。
   - 已有适用的知识库标准单价时，可以填充报价明细、分项价格、工价清单等价格槽位，并以“标准单价参考”表达。可与项目总预算独立展示，无需提供工程量、小计或与总预算加总一致；不得把“报价明细”一律理解成实际成交明细，也不要求覆盖全部装修类别。仅明确依赖真实成交、结算或实际节省结果的核心槽位仍需实际项目证据。
2. 全部合格卡片按 `strategy_candidates.scoring.reference` 的权重及 0—4 锚点评分；适配策略维度以刚选择的公式和手法为依据，但 input_paths 仍指向本次简报或真实业务证据。
3. 按总分、指定同分维度、最后稳定 ID 选择唯一参考。每项保留一句理由及实际非空输入路径，不输出整篇候选复述。
4. 按 `reference_policy.required_slot_mode` 提交 `slot_mapping`。键必须来自当前选中卡片，值为本次输入路径列表。引用原文、空字段或其他案例不能证明当前项目事实。
5. 只复制 selected_asset_id 和 source_hash，不提供 reference_blueprint。已准备蓝图在锁定步骤直接读取。
6. 无合格候选返回 no_candidate/needs_input 及缺口；不触发在线补建资产，也不自动改为原创。
