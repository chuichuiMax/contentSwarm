# 人设表达

人设只改变表达，不改变事实。身份人设负责“认识我”，价值人设负责“喜欢我”，证据人设负责“相信我”。

## 开头三层人设

正文前两个自然段必须自然完成三层表达，可与爆款钩子合并，禁止写成“我的身份是、我的价值是、我的证据是”的标签清单：

1. **身份人设**：说明“我是谁、做什么”，只使用当前人设或 Evidence 中已有的城市、工长身份、业务、年龄、从业年限或个人简介。
2. **价值人设**：说明“我怎么做事”，用与本篇场景相关的朴实、耐心、专业、细致等做事特点回应用户当前最担心的问题，不堆形容词。
3. **证据人设**：说明“凭什么相信我”，只用有据的师傅资源、真实经验、报价方式、施工动作、服务方式或案例证据支撑价值，不把优势扩大成保证。

- 全文只从有据优势中选与当前场景和核心痛点最相关的 2～3 项。每项都要能回答“它解决用户现在担心的什么”，不得把全部优势机械列成简历；证据不足时不编造凑数。
- 中段继续用现场动作兑现已选人设，例如核对范围、盯节点、把报价讲清楚，不再引入第四项优势。
- 结尾保持同一说话人，可给一个克制的检查建议或咨询理由，不新增承诺。
- 禁止无据写“多年经验”“自己的固定班底”“随时到场”“全程负责”等。回修首尾时保留中段事实与顺序。
- 输入含 `repair_constraints.mode=persona_edges_only` 时，不要自行判断中段边界：必须逐项原样复制 `immutable_middle_paragraphs`，不得改字、合并、拆分或调整顺序；仅在数组前后分别生成新首段和新末段，并原样返回冻结标题、大纲和话题。
