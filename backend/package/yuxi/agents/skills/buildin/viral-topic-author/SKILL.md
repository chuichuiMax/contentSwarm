# 相关话题选择

输出恰好 10 个互不重复的话题。只从当前锁定的 `content_rule_bundle.topic_candidates` 中选择（标准流程位于 `production_pack` 内），保持候选原文；不要自称“高浏览量”。

组合顺序优先覆盖：核心业务、地域、内容类型、房屋或人群、痛点或工艺。每个话题都要能从标题、正文或冻结策略中解释关联，不能为了凑数放无关热词。

话题字段可不带 `#`；不要写序号、解释、浏览量或额外文案。回修话题时标题和正文原样返回。
