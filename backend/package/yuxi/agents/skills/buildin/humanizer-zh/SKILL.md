# 中文自然化编辑

## 工作流程

1. 确认文本用途、受众和语气。用户没有说明时，沿用原文语域，不擅自改成口语或第一人称。
2. 标记机械表达。需要完整模式和例子时读取 `references/patterns.md`。
3. 先删空话，再重组句子，最后调整节奏。不要逐词替换同义词。
4. 逐项核对事实、数字、专名、引用、因果关系、承诺和立场。
5. 通读改写稿，确保它自然但不随意，清晰但不失原意。

## 必须遵守

- 保留可验证信息。不得凭空增加案例、数据、用户反馈、引语、来源或个人经历。
- 原文含模糊归因时，删除无信息量的权威背书，或明确标注需要来源；不要伪造来源。
- 不把所有文本都改成“有个性”的博客腔。正式报告、学术摘要、客服回复和品牌文案应保持各自语体。
- 不机械禁止某个词、破折号、三项列举、粗体或“此外”。只有当它们密集、公式化或无助于表达时才调整。
- 保留 Markdown 结构、链接、代码、变量名和用户指定格式，除非用户要求重排。
- 不承诺绕过 AI 检测。目标是提升写作质量和真实性。

## 编辑重点

- 用具体事实替代抽象意义、宏大判断和宣传性形容词。
- 删除“值得注意的是”“毋庸置疑”“在不断演变的格局中”等无信息量铺垫。
- 将连续同构句、固定三段式和“不是……而是……”模板改成符合内容关系的结构。
- 减少每段机械使用“首先、其次、此外、最后”；允许逻辑通过句意自然衔接。
- 长短句交替，段落结尾不要总落在口号、展望或总结金句上。
- 能用“是、能、有、因为”直接表达时，不绕成“作为、赋能、致力于、彰显”。

## 输出

默认只给改写后的完整文本。用户要求审阅、对比或解释时，再附简短修改说明；不要输出冗长评分表。若原文缺少支撑关键断言的信息，保留事实边界并指出需要补证据的位置。
