# 行业策略评分

读取运行时 `strategy_candidates` 中的评分标准和候选，不凭记忆补候选或权重。标准来源为正式规则资源 [selection-policy.json](../content-strategy-planner/references/selection-policy.json)，实际使用任务锁定快照。

1. 所有行业的手法独立评分；只有 `strategy_mode=scored` 才对标题/正文公式评分。不得为非装修行业强制选择 CT01—CT07 或装修方向。
2. 先检查资料和适用条件。必要事实缺失、明确冲突或禁配即淘汰，不能靠其他高分抵消。待检索的资料不能冒充已经确认的当前项目事实。
3. 对每个合格候选逐维提交 0—4 整数得分、简短理由及非空输入字段路径。0=无依据或冲突，1=宽泛相关，2=部分直接支持，3=大部分直接支持，4=充分直接支持。未知软偏好记 0 并说明未知。
4. 百分制总分由结果工具按给定权重计算，total 可省略，不能自行加减权重。候选顺序不是分数。保留全部被评价候选及拒绝原因，不宣称评价未读取的规则。
5. 必须按自己提交的逐维分数选择最高分兼容配对：单项分数=Σ(维度分/4×该维度权重)，配对分=标题分×title权重+正文分×body权重。不能在已给低分的配对上再凭主观偏好选中。同分按规定维度、最后按稳定 ID 比较；两边都同分且维度也相同时，编码字典序较小者优先。提交前核对选中编码，不能让理由里的偏好与分数排名冲突。
6. 选择一个主手法。辅助手法仅在有清晰的补充作用且兼容时使用，不为凑数量整组照搬。
7. `input_paths` 使用 `content_brief` 或当前 `evidence_bundle` 的实际字段路径；无依据不得编造路径。无合格结果返回缺口，不采用候选首项兜底。

仅提交结构化决策，不生成正文或详细蓝图。
