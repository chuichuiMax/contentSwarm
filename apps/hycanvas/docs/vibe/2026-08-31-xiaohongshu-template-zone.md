# 小红书模板专区

## 目标

把首页单一的“小红书模板”快捷入口升级为模板专区，并补齐常见的小红书内容场景。

## 范围

- 保留现有“爆款笔记封面”。
- 新增装修、干货清单、产品种草、探店打卡、穿搭分享、美妆教程、情绪语录、活动促销 8 套模板。
- 首页入口改名为“小红书模板专区”。
- 点击入口进入模板页，同时展示小红书设计稿和带“小红书”标签的可复用模板。
- 设计稿的专区归属持久化在设计摘要中，不依赖标题实时判断；历史同名设计一次性回填。
- 从专区设计稿“保存为模板”时，后端以设计摘要为准自动继承“小红书”分类与标签，兼容快照元数据为空的历史稿。
- 自定义模板卡片提供独立的“重命名”操作，原地更新模板标题与更新时间；不复用会复制资源的“保存为模板”，也不应用模板创建新设计。
- 从带“小红书”标签的模板创建设计时，新设计继续携带专区归属，后续保存为模板仍可回到专区。
- 模板只使用文字和可编辑几何图形，不引入外部图片素材。

## 验收标准

- [x] 内置模板种子包含 9 套小红书模板。
- [x] 9 套模板均为 1080 × 1440，编译和 Schema 校验通过。
- [x] 首页“小红书模板专区”入口可进入模板页。
- [x] 专区可直接展示并打开小红书设计稿，包括修复前已创建的历史稿。
- [x] 历史稿保存为模板后可立即通过小红书标签进入专区。
- [x] 重命名后模板 ID 和模板总数不变，卡片标题即时更新；空标题、越权修改及内置/公共模板修改被后端拒绝。
- [x] 应用小红书模板创建的设计继续显示在专区中。
- [x] 专区不会混入非小红书模板，并可返回全部模板。
- [x] 中英文界面文案完整。
- [x] 前端 Lint、生产构建及运行容器健康检查通过。
