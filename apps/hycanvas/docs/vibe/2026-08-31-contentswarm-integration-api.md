# ContentSwarm 模板实例化接口

## 目标

为 ContentSwarm 提供受工作区 API Key 保护的模板自动填充能力，同时保持 HyCanvas 为独立服务。

## 范围

- API Key 的 `read` 权限可读取工作区可见模板。
- API Key 的 `generate` 权限可调用模板实例化接口。
- 实例化请求按模板 `fillableFields` 的中文标签填充文字节点。
- 只允许在 API Key 所属工作区创建设计稿。
- 保留原文字样式和画布结构，设计稿节点 ID 与模板解耦。
- 运行镜像安装 Noto CJK 字体，保证服务端 PNG 输出中文完整。
- 模板可声明图片填充字段，实例化时将上传图片嵌入对应节点并保留原节点几何位置。

## 验收标准

- [x] 未声明的填充字段会被拒绝。
- [x] 填充文字保留原字体和段落样式。
- [x] API Key 不能跨工作区创建设计稿。
- [x] 模板和 HTTP API 相关 Go 测试通过。
- [x] Docker 运行服务完成 ContentSwarm 真实请求联调。
- [x] 未声明的图片字段被拒绝，声明的主图替换保留模板位置和尺寸。
