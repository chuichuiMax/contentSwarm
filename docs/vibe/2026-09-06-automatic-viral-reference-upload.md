# 知识库上传自动准备仿写参考

## 目标
上传时只选择“用于爆款仿写参考”。解析成功后异步识别完整文章和行业、登记版本并准备参考卡与结构蓝图。用户指定参考用途不冒充平台爆款证明。不要求填写排列方式、标题正文列和认定依据。

## 范围与验收
- [x] 文件/文件夹/工作区/URL 上传统一传递用途，未勾选不触发。
- [x] 解析成功即触发，不依赖向量索引完成；重解析继续使用用途标记。
- [x] Agent + 正式 Skill 识别文章，代码按来源单元精确提取，禁止改写原文。
- [x] 行业优先继承知识库配置，无配置时识别；不默认套装修。
- [x] 独立任务状态、权限、去重、版本失效和失败重试。
- [x] 已有文件可以多选自动准备；原手动表单移除。
- [x] 卡片和蓝图可读展示，缺原文/报价表等明确显示问题。
- [x] Docker 行为测试、真实上传/Agent/Worker链路、浏览器、Lint 与构建。

## 执行边界
本地开发，不部署云端，不批量处理用户存量文件；使用隔离合成样例验证。保留既有工作区改动。


## 实现入口
- 上传选择：`web/src/components/FileUploadModal.vue`。
- 解析后触发：`backend/package/yuxi/knowledge/manager.py`。
- 识别单元与契约：`content/model/viral_document.py`。
- 文件任务服务与 Worker：`services/viral_document_service.py`、`viral_document_worker.py`。
- 正式标准：`viral-document-detector`（新增，1.0.1）、`viral-asset-preparer`（1.1.0）；资产 Agent 配置版本 3。
- 进度与卡片界面：`web/src/components/content/ContentViralAssets.vue`。

文件识别一次，单篇蓝图分别异步准备；当前单文件最多识别 100 篇，超过 12 万字符明确提示按完整文章拆文件。不会静默截断正文。现有知识库可在 additional_params.industry_slug 配置行业；未配置则由 Agent 在已支持行业中识别。
