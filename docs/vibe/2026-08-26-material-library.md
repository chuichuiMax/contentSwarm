# 素材库与 image 桶迁移

## 目标

- 在主导航“工作区”上方新增“素材库”。
- 素材库包含“素材图片”和“封面模板”两个模块。
- 素材库对象统一写入私有 MinIO 桶 `image`，对象路径按用户隔离。
- 复用 `ContentCoverAsset` 保存文件事实，新增素材库目录项保存名称、受控分类和状态；素材库业务不再使用标签。
- 封面模板继续复用现有大字报分析与封面生成链路。
- 下线与素材库重复的旧“封面管理”入口、页面、权限项和 `/api/covers` 管理接口；保留“封面生成”及其 `/api/content/covers` 链路。
- 提供可 dry-run、幂等、可校验、可回滚的历史素材迁移工具。

## 范围

- `source` 迁入“素材图片”。
- `template`、`mask`、`poster_template` 对象迁入 `image` 桶；`template` 与 `poster_template` 展示在“封面模板”，`mask` 仅作为内部资产，不单独展示。
- `output`、OCR、知识库、头像、工作区和对话附件不迁移。
- 迁移只复制对象并切换数据库引用；旧对象保留，不在本需求中清理。

## 信息架构与分类标准

- “素材图片”先展示图库文件夹，进入图库后再展示图片网格。首次使用为每个用户创建产品商品、人物、场景、背景、装饰、品牌、未分类等默认图库；用户可继续新建图库，也可编辑图库名称和说明。
- “封面模板”直接使用 3:4 竖版大字报墙，按用途筛选。首次使用提供产品推广、营销促销、知识科普、攻略清单、测评对比、活动招募、节日节气、品牌宣传、生活方式、其他、未分类等默认分类；用户可在分类管理中新增、重命名、修改说明和删除非系统分类。
- 图库与模板分类均使用账号隔离的稳定 ID 持久化，同名校验不区分大小写；接口同时返回名称、说明、排序、素材数量和系统兜底标记。
- “未分类”是唯一不可删除的系统兜底项。删除非系统图库或分类时，已有素材必须在同一事务内迁移到用户指定的目标项，默认迁往“未分类”；此操作不删除或移动 MinIO 对象。
- 新上传素材必须且只能选择一个当前账号下有效的图库或分类；历史中文分类兼容映射，无法识别或已失效的旧值统一归入“未分类”。
- 数据库中的历史标签列仅保留兼容，不再由素材库接口读写、搜索或返回。
- 图库卡片展示代表图、素材数量和说明，提供独立的进入、编辑、删除操作；图库内支持名称搜索、时间/名称排序、分页、预览、下载、重命名、移动图库和删除素材。
- 封面模板卡片突出竖版画面、名称和用途分类，继续兼容现有大字报模板分析、标注与生成能力；分类变更同步到素材库目录项与封面模板记录。

## 验收清单

- [x] 新上传素材的 `bucket_name` 恒为 `image`。
- [x] 对象路径为 `material-library/{owner_uid}/{images|cover-templates}/...`。
- [x] 素材图片以“图库 → 图片网格”两级结构展示，封面模板以竖版大字报墙展示。
- [x] 素材图片支持新建图库、编辑名称与说明、删除非系统图库；封面模板分类支持新增、编辑和删除。
- [x] 图库与分类严格按用户隔离，同一用户同一素材类型下不允许重名。
- [x] 删除含素材的图库或分类时先迁移归属，不删除或移动 MinIO 对象；“未分类”不可删除。
- [x] 两个素材模块均支持点击选择或拖拽批量上传，以及列表、搜索、分类筛选、排序、预览、下载、编辑分类和删除。
- [x] 新上传必须选择当前账号下有效的图库或分类，页面与素材库 API 均不出现标签字段。
- [x] 用户不能访问其他用户的素材。
- [x] 新封面模板可在现有封面生成中选择和使用。
- [x] 侧栏、前端路由、权限配置和后端路由中不再出现旧“封面管理”，直接访问 `/api/covers` 不再提供服务。
- [x] 迁移 dry-run 无写操作，apply 可重复执行，rollback 可恢复原引用。
- [x] 迁移后素材库有效条目关联的对象全部位于 `image` 桶且哈希一致。
- [x] `mask` 对象迁入 `image` 桶，但素材库列表中不创建独立展示条目。
- [x] 单元、集成、E2E、前端 Lint 与 Build 通过。
# 内容任务视觉素材绑定扩展

## 目标

在内容任务阶段一底部增加“图库图片”和“封面模板”选择器。图片必须从当前用户的素材库图库中选择且只能选择一张；封面模板从当前用户已启用的大字报模板中选择，允许不选。选择结果不是页面临时状态，而是内容任务的持久化输入和 V3 运行快照的一部分。

## 验收标准

- 刷新、草稿自动保存、进入 V3、失败重试和 checkpoint 恢复后，所选图片与模板保持一致。
- 编译事实简报时必须有且仅有一个有效图库图片；模板为零或一个。
- 后端校验素材归属、类型、启用状态和底层文件记录，不能通过接口引用其他用户或已删除素材。
- V3 视觉规划只能使用已选择的图片；选择模板时，封面提交固定进入对应大字报模板生成链路，并以选择的图库图片作为产品图。
- 编译后把素材 ID、资产 ID、校验和与模板版本写入不可变运行快照；后续重试不重新解析“当前模板版本”。
- 仍被未删除内容任务引用的图片或模板禁止删除，避免历史任务和恢复流程失效。
- 任务页不提供本地上传入口，只提供前往素材库管理素材的入口。
- 任务页只展示图库文件夹卡片；点击文件夹后在弹框中展示该图库的已启用图片，单选后必须确认才更新任务选择。
- 关闭弹框后主页面持续展示已选图片及所属图库，并支持更换或清除；空图库显示明确空状态。
- 内容任务的模板列表必须直接读取素材库完整分页数据，数量、名称、分类、顺序和状态保持一致；待标注或已停用模板同步展示但禁止选择。
- 素材库发生新增、重命名、换分类、启停或删除后，内容任务页面激活时立即刷新，并在可见期间最多 10 秒内自动响应。
