# 创作规则库原文补全

目标：以飞书《小红书自运营内容生产工具V2.0设计框架》8月29日版本为唯一内容来源，补全标题公式、正文公式、组合矩阵，并支持管理员编辑、启停、删除。

来源：https://fycrbjmor5.feishu.cn/wiki/W1fhwWyKGi86ABkz1VTcBmWJnEf

## 范围与验收

- [x] 7个标题公式：名称、适用场景、核心、案例、变量说明及情绪词库按“3、标题公式”录入。
- [x] 4个正文公式：名称、适配手法、适用场景、核心、四段结构、三组案例、三类变量按“4、正文公式”录入。
- [x] 7个方向、28个组合：保留飞书顺序、标题及正文候选顺序、适配场景原文；其他行业通过筛选查看。
- [x] 管理员可创建草稿、编辑、启停、删除、保存、发布；历史任务继续绑定原版本。
- [x] 停用公式保留原始组合引用，运行时过滤停用候选；候选全部停用的组合不参与匹配。
- [x] 组合启停复用持久化 compatibility 字段，API显式返回 enabled。
- [x] 容器测试、Lint及浏览器端到端验收：67项单元测试、2项真实HTTP测试通过；页面验证编辑、启停、删除、保存、刷新及放弃测试草稿，最终保留v4原文发布版。

## 数据导入
