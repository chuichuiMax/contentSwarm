# Agent + Skill 策略与爆款选择改造

## 目标

将创作手法、标题公式、正文公式和爆款参考的业务选择标准从固定代码顺序迁移到版本化 Skill，由 Agent 输出可审计评分；代码仅保留候选池、契约、权限、阈值校验、节点编排和断点恢复。

## 范围

1. 策略 Agent 对候选创作手法、标题公式、正文公式执行硬性淘汰和加权评分，不再直接取候选列表首项。
2. 爆款原文建立文章级结构画像；Excel/Markdown 表格按“标题+文案”逐行拆成完整文章，运行时不再把任意知识库分块当成完整爆款。
3. 爆款匹配 Agent 对结构画像执行硬性淘汰和加权评分，输出唯一参考及完整审计依据。
4. 内容生成复用已选结构画像；选择节点不再重复抽取复杂蓝图。
5. 节点失败时保留已完成节点输出，只重试失败节点。

## Agent 与 Skill 边界

- Skill：维护评分维度、权重、淘汰规则、最低分、输出要求。
- Agent：读取当前任务输入和候选池，按 Skill 完成比较与选择。
- 数据库：保存公式、手法、爆款文章、结构画像、Skill/模型版本、原文哈希与选择快照。
- 代码：装配输入、暴露工具、验证候选 ID/分数/必填槽位、编排与恢复；不得代替 Agent 选择首项。

## 验收标准

- 相同候选池中，策略结果能展示每个手法和公式的分项得分与淘汰原因。
- 用户变量变化能影响最终手法和公式，不能只由数组顺序决定。
- 爆款候选必须来自完整、已建立结构画像的爆款原文；报价表和普通业务资料不能冒充爆款。
- 同一 Excel 中的多篇原文必须拆成多个文章级候选，不能把整个表当成一篇，也不能按文件 ID 错误去重。
- 爆款选择展示候选对比、结构可填充度、使用的用户字段路径和未填槽位。
- 最高分不足阈值时明确阻断，不随机选择且不静默降级原创。
- 运行时不再串行调用“候选全文分析 Agent + 结构蓝图 Agent”。
- 策略选择不超过 10 秒，爆款画像检索不超过 3 秒，爆款匹配不超过 10 秒；整体目标不超过 60 秒。
- 相关单元、契约、工作流、集成和关键 E2E 测试通过。
