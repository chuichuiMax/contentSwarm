# 内容工作流执行轨迹

## 目标

右侧“运行详情”像 Codex 一样持续输出可观察的执行过程，包括节点输入、Agent/Skill/工具调用、知识库命中内容、结构化结果、规则校验和失败原因；不输出模型隐藏思维链、密钥或未受控的完整内部对象。

界面使用中文字段和内容卡片展示 Agent 提交的选择理由与产出，不以 JSON 或代码形式呈现。

## 验收标准

- [x] SSE 持续推送节点、Agent、Skill、工具和知识库的可读详情。
- [x] 知识库事件包含查询词和有限长度的命中片段。
- [x] Agent 与固定节点完成后包含结构化结果预览。
- [x] 前端支持展开详情，完成、失败和刷新恢复后仍可查看。
- [x] 事件内容有字段过滤、长度和数量上限。
- [x] 相关单元测试、Lint 和构建通过。
