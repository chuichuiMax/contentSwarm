# 基于资料与蓝图卡的自动创作选择

## 已确认需求

用户最新确认：取消用户选择内容方向，由 Agent 根据实际资料与爆款蓝图卡判断，减少执行时间。此前的“独立判断资料再调整方向”方案不再实施。

## 最终流程

填写资料 → 装配行业候选、检索已准备参考卡及结构摘要 → 一个选择 Agent 同时判断资料适配、参考文章、内部方向、公式及手法 → 读取选中蓝图 → 创作。

- 装修：方向仅作为内部规则索引。Agent 根据真实资料和参考结构采用方向，再在该方向内匹配标题、正文公式，公式不打分。
- 其他行业：不套装修方向，公式和手法继续独立评分。
- 仿写：必须比较文章级参考卡，事实槽位能被当前资料填充才合格，选最高分项；匹配不到时展示具体缺口，不编造事实、不自动切换原创。
- 原创：没有参考选择，Agent 依据资料采用适用方向/行业公式。
- UI：新入口不显示内容方向选择，结果说明自动采用的方向和原因。
- 代码负责候选范围、权限、检索、证据校验、计分、版本锁定；语义判断由正式 Skill 约束的 Agent 完成。

## 性能范围

维持 25 个工作流节点，不增加独立资料判断模型调用；单次参考检索，最多比较配置上限的卡片（当前 5 篇）。检索覆盖卡片与预制蓝图结构摘要，线上只读取选中单篇蓝图，不阅读全文重新解析。检索相关度只负责召回，不作为最终选择分数。
