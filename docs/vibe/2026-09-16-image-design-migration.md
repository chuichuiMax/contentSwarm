# 图片设计模块迁移

## 目标

将现有图片设计能力作为一个完整领域迁移到 `contentSwarm` 主线，并适配目标仓库当前架构。迁移只包含图片设计及其直接依赖，不带入来源分支的小红书、爆款样例等无关改动。

## 范围

- 三套工作流：风格迁移、空间效果适配、跨空间迁移。
- 复用素材库中的个人与企业共享图片，保持用户归属和访问隔离。
- 按素材内容、分析角色、模型与 schema 版本执行真实视觉分析和缓存。
- 使用确定性的 PromptPlan 编译与覆盖校验，持久化优化快照、分析依据、冲突和约束。
- 支持用户编辑优化提示词后重新校验；生成接口只能引用服务端优化快照。
- 通过 ARQ Worker 调用 image2，保存任务、结果资产与可追溯输入快照。
- 提供前端工作台、导航、状态轮询、结果下载和删除。
- 提供单元测试、接口契约测试和固定 30 用例 E2E 质量门禁。

## 验收标准

- 三套工作流使用各自严格请求 schema，跨工作流字段被拒绝。
- 素材视觉分析不是浏览器伪造文本，且缓存键能区分角色、模型和 schema 版本。
- 工作流方向、素材角色、硬约束、目标空间和画幅均进入最终提示词；冲突可见且有确定优先级。
- 生成请求不能直接提交任意提示词，Worker 使用与优化快照一致的服务端编译结果。
- API、Worker、数据库模型和前端路由完整注册；普通用户只能访问自己的客户、任务和结果。
- 相关单元测试、Lint、前端构建通过；外部模型和账号具备时可运行固定 30 用例评分报告。
