# 策略锁定前报价补证

目标：仿写资料缺报价时先检索价格库，保留来源、单位、适用范围，经用户确认后复评。保留原简报及历史发布工作流。

- [x] 新版工作流：策略初评 → 报价检索 → 逐项确认 → 合并证据 → 一次复评 → 锁定。
- [x] 初评无价格缺口时不调用价格 Agent、不重复策略推理。
- [x] 标准单价与本项目实际报价分开，禁止按房屋面积推算所有工序工程量。
- [x] 标准单价可独立用于报价明细或工价参考，与项目总预算无需对应或加总一致；不因缺工程量、小计或未覆盖全部类别阻断。只有明确表达实际成交、结算或实际节省结果时才要求相应项目证据。
- [x] 空命中仍复评并报告实际剩余缺口；检索异常显式失败。
- [x] 原工作流和快照兼容；新版本显式迁移行业入口。
- [x] 容器单测、Lint、真实 Worker 检索及用户确认界面验证。

新版本 `content-workflow-blueprint-first-v2`，旧版定义不改写。新报价证据在确认前只存在于调研结果，不修改冻结证据包；确认后通过现有 Evidence 版本服务生成新包，再复评。后续价格节点跳过同次重复检索。

检索输出上限8条，每条为不超过400字的具体报价。source_hash 和 source_version 由提交器根据本次实际检索文本计算，不交给模型生成。缺少可访问价格库属于配置错误，显式报错，不要求用户补材料。

已验证：273项相关单测及10项真实API/迁移集成测试通过；随后新增来源哈希测试，相关115项通过。前端 ESLint 和限制 Node 堆内存及并行度后的生产构建通过。真实 Worker 端到端测试通过（162.94秒）：检索价格库 → 逐项确认 → 冻结带哈希的价格证据 → 策略复评。

原任务已在保留简报的前提下切换新版并重跑，实际检索到8条报价证据。浏览器已验证完整报价、来源文件、单位、范围、标准单价提示及未勾选时禁用提交。用户确认后曾被旧规则要求实际分项金额而失败；更新标准单价规则及重试路径后，已保留8条已确认报价通过复评和锁定，浏览器确认恢复正文生成。原任务、检查点及行业入口切换均留有本地临时备份。

标准单价口径同步覆盖价格调研、联合选择、已准备参考选择、正文生成、结构仿写与内容审核的正式 Skill。已通过47项相关单测与 Lint，新增回归覆盖18万元预算与42.8元/㎡标准价独立存在、无工程量时仍可映射报价槽位。真实 Worker 端到端测试通过（225.47秒）：标准价检索、确认、复评锁定、正文生成及确定性校验；正文直接展示具体标准单价，预算单列。

新版本在报价补证后的策略锁定失败时，点击重试会保留已确认价格，回到策略复评；不会只重复锁定被拒结果。历史工作流、已经选中参考的锁定重试和未补证任务保留原路径。语义审核按原任务配置执行，未额外开启严格审核。
