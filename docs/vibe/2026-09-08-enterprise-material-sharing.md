# 企业共享素材图库

## 目标和范围

本站所有登录账号属于同一企业，不按 department_id 划分共享范围。实现“我的素材”和“企业共享”，不向匿名访问者开放。此次共享针对图片图库，模板及设计文件的协作权限保持现有语义。

## 权限和数据规则

- 管理员创建、调整和删除共享图库；子图库继承一级图库共享范围。
- 所有成员可浏览、搜索、上传、插入和生成；上传者管理自己的图片，管理员管理共享图片。
- 私有图库、原图读取仍限制本人；服务端统一校验，不能靠前端隐藏按钮。
- 图片上传者与图库归属分别记录。默认图库的短 ID 在多个账号中重复，转共享时仅替换图库 ID 并更新关联，图片 ID、原图和作品引用保持不变。
- 已有素材默认 private，不自动共享。共享图库含其他上传者素材时，需先迁移到其他共享图库才能改回私有。
- 共享过的素材删除只移出素材库，保留原图；已授权任务记录素材使用关系，后续下架不破坏该任务。HyCanvas 插入保留现有设计内图片快照。
- 上传、移动、共享范围调整、删除记录操作者及对象 ID。

## 验收 checklist

- [x] 管理员建立共享图库，其他部门的普通成员也可使用。
- [x] 普通成员不能改共享图库或他人原素材；能管理自己上传的素材。
- [x] 个人图库仍隔离，匿名访问不可读。
- [x] 父子图库范围一致，老图库转共享、单图移动正常。
- [x] 编辑器、内容选图、后台成图读取共享图；浏览器保存重开正常，HyCanvas 渲染接口导出 PNG 正常。
- [x] 下架共享素材不破坏已有任务和作品；新任务不能再选。
- [x] Docker 中相关单元、API 集成、端到端检查和 Lint 通过。

包含新增字段及使用关系表，需要包含数据库迁移的发布流程；现有图库保持私有，不执行批量公开。

## 验证记录

- Docker API 集成验证管理员、普通成员及不同部门成员的访问权限，私有图库、匿名访问、父子范围继承、单图移动和整库迁移均通过。
- 真实 Worker E2E 覆盖共享图写入任务草稿、组合槽位解析、提交后立即下架、授权原图读取和 PNG 生成。

- ContentFlow 与 HyCanvas 的 Docker 生产构建及本次修改文件 Lint 通过。修正 HyCanvas 可选路由首页参数的现有 TypeScript 错误，保证生产构建可用。
