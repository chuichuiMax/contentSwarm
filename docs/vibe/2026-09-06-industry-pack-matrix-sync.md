# 行业包与创作矩阵同步

目标：更新组合矩阵后，同步行业包的组合引用、方向名称、结构样本与规则版本绑定，使选择行业的新任务使用同一版本关系。

业务策略、变量映射、词库、合规和审核要求继承现有已发布行业包。结构样本只验证组合引用，不代表模型生成效果或完整 canary 通过。
