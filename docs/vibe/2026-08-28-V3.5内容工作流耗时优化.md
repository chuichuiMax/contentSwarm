# V3.5 内容工作流耗时优化

## 目标

在不降低公式锁定、证据追溯和审核约束的前提下，减少内容工作流中的无效模型往返和不必要的调研 Agent 调用。

## 范围

- 结构化节点结果提交成功后立即终止 Agent 工具循环。
- 业务简报已经包含人物、项目与痛点时，确定性形成 `scene` 证据。
- 没有真实证据缺口时跳过 `collect_missing_evidence`。
- 保留固定规则校验、语义审核和人工审核，不以跳过质量关口换取速度。
- 运行详情继续显示节点跳过原因和可追溯证据。

## 验收标准

- [x] `submit_content_node_result` 校验成功后，在工具节点固定回边再次调用模型前结束同步或异步循环；完整 `create_agent` 编图回归确认不会发生第二次模型调用。
- [x] 结构或业务校验失败时仍允许 Agent 修正后重新提交。
- [x] `audience`、项目描述和业务痛点齐备时生成来源明确的 `scene` 证据。
- [x] 只有缺少真实来源时才委派调研 Agent。
- [x] 现有内容工作流单元测试通过。
- [x] Docker 中完成相关测试与 Ruff；完整后端测试 1248 项通过、161 项按环境跳过，另有 2 项与本次无关的既有导入失败。
- [ ] 使用同类真实任务复测节点耗时，确认没有超时、重试或审核状态回退。
